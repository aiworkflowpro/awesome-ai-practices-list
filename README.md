## Using the data

Download [posts.jsonl](data/posts.jsonl), [weekly.jsonl](data/weekly.jsonl) or [monthly.jsonl](data/monthly.jsonl). Each non-empty line is a JSON object; an empty file means no published entries of that kind. See the [data guide](data/README.md) for fields and stable identifiers.

Source records contain authorship, links, dates, tool tags and metadata summaries, not original post text or media. Editorial records include our full perspectives and citation links. Corrections retain publication IDs; removed material disappears from the current collection. Inclusion is not a claim of independent reproduction or an endorsement.
