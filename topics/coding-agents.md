### The week in coding agents

OpenAI Developers' posts emphasized account switching and Codex usage visibility, while VS Code described agent-session controls and Vercel reported first-day AI Gateway adoption for Jev. [OpenAI Developers · 2100980899655389392](https://x.com/OpenAIDevs/status/2100980899655389392) [OpenAI Developers · 2100733364877803741](https://x.com/OpenAIDevs/status/2100733364877803741) [Visual Studio Code · 2100309875829907552](https://x.com/code/status/2100309875829907552) [Vercel · 2101077346203971900](https://x.com/vercel/status/2101077346203971900)

#### What changed

- OpenAI Developers said multi-account support is now available across most plugins, framed around personal, work and side-project accounts. [OpenAI Developers · 2100980899655389392](https://x.com/OpenAIDevs/status/2100980899655389392)
- OpenAI Developers introduced usage visibility that breaks Codex usage down by tasks, subagents and individual chats, reachable in Settings on the desktop app for personal, Business and eligible Enterprise accounts. [OpenAI Developers · 2100733364877803741](https://x.com/OpenAIDevs/status/2100733364877803741) [OpenAI Developers · 2100733366438150546](https://x.com/OpenAIDevs/status/2100733366438150546)
- OpenAI Developers brought Appshots to Windows so ChatGPT can take context from the apps a developer is working in. [OpenAI Developers · 2100726653366534560](https://x.com/OpenAIDevs/status/2100726653366534560)
- OpenAI Developers added a voice agent in Codex, which it says is powered by GPT-Live-1. [OpenAI Developers · 2100677280297324759](https://x.com/OpenAIDevs/status/2100677280297324759)
- Visual Studio Code announced a release with new ways to work with agents, move between environments and keep sessions organized, plus agent-window background customization and a preview application badge for agent sessions needing attention. [Visual Studio Code · 2100309875829907552](https://x.com/code/status/2100309875829907552) [Visual Studio Code · 2100948707747443037](https://x.com/code/status/2100948707747443037) [Visual Studio Code · 2100309882792559023](https://x.com/code/status/2100309882792559023)
- Vercel reported that Jev was adopted faster than any other model in AI Gateway history, reaching roughly 13% of teams in the first day, which it describes as 2x the GPT-5.6 family and 6x Fable 5.1. [Vercel · 2101077346203971900](https://x.com/vercel/status/2101077346203971900)

#### Worth trying

- Teams using Codex can check the new usage breakdown to see how tasks, subagents and chats contribute before changing their workflow, per OpenAI Developers. [OpenAI Developers · 2100733364877803741](https://x.com/OpenAIDevs/status/2100733364877803741) [OpenAI Developers · 2100733366438150546](https://x.com/OpenAIDevs/status/2100733366438150546)
- Developers on Windows could try Appshots to feed app context into ChatGPT instead of copying and pasting, as described by OpenAI Developers. [OpenAI Developers · 2100726653366534560](https://x.com/OpenAIDevs/status/2100726653366534560)
- VS Code users could enable the preview sessions showApplicationBadge setting to be notified about new results, input requests or pull request checks, according to the VS Code team. [Visual Studio Code · 2100309882792559023](https://x.com/code/status/2100309882792559023)

#### Watch next

- The reported first-day Jev adoption numbers come from Vercel's own AI Gateway and are not an independent measurement of model quality or suitability. [Vercel · 2101077346203971900](https://x.com/vercel/status/2101077346203971900)
- OpenAI Developers' voice agent in Codex is an author-stated feature description, so what it does well in real repos remains unverified here. [OpenAI Developers · 2100677280297324759](https://x.com/OpenAIDevs/status/2100677280297324759)
