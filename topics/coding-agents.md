### The week in coding agents

This week brought a wave of vendor announcements for coding agents, from new frontier models and cheaper inference to observability, rollouts, and parallel execution surfaces. [OpenAI Developers · 2102461432684282061](https://x.com/OpenAIDevs/status/2102461432684282061) [Cursor · 2102861817160904808](https://x.com/cursor_ai/status/2102861817160904808) [GitHub · 2104298872029741366](https://x.com/github/status/2104298872029741366) [LangChain · 2103135612832547170](https://x.com/LangChain/status/2103135612832547170)

#### What changed

- OpenAI Developers said GPT-6 Sol and Luna launched with API prices 50% lower than GPT-5.6, and that GPT-6 prompt caching was improved with higher default cache-hit rates and cached-input discounts of up to 90%. [OpenAI Developers · 2102461432684282061](https://x.com/OpenAIDevs/status/2102461432684282061) [OpenAI Developers · 2102506476401258678](https://x.com/OpenAIDevs/status/2102506476401258678)
- Cognition said GPT-6 Sol and Luna are available in Devin, with Sol matching GPT-5.6 Sol on FrontierCode 1.1 at 61% lower cost per task and Luna scoring above GPT-5.6 Luna at roughly a quarter of the cost. [Cognition · 2102463672224543018](https://x.com/cognition/status/2102463672224543018)
- Cursor said Claude Opus 5.5 is now the top model on CursorBench at 57.8% (Max) and costs 40% less per task than Opus 5, while separately reducing Cursor token costs by 7% through tighter prompts, selective tool loading, better caching, and compressed file reads. [Cursor · 2102448392773435706](https://x.com/cursor_ai/status/2102448392773435706) [Cursor · 2102786814633464159](https://x.com/cursor_ai/status/2102786814633464159)
- Cursor introduced Rollouts, which write a monitoring plan and watch changes during deployment with verified deployments, and updated Security Reviewer to finish 21% faster at 3.8 minutes on average. [Cursor · 2102861817160904808](https://x.com/cursor_ai/status/2102861817160904808) [Cursor · 2102861818905727328](https://x.com/cursor_ai/status/2102861818905727328)
- LangChain announced several Interrupt NYC items including LangSmith Engine v2 for proactively spotting agent issues, Trajectories, and Fine-Tuning with the smithtune CLI in public beta, plus Managed Deep Agents 0.8 with user-owned credentials and memory. [LangChain · 2103530944645017662](https://x.com/LangChain/status/2103530944645017662) [LangChain · 2103135612832547170](https://x.com/LangChain/status/2103135612832547170) [LangChain · 2103169043368706173](https://x.com/LangChain/status/2103169043368706173) [LangChain · 2103182716720099748](https://x.com/LangChain/status/2103182716720099748) [LangChain · 2103152512693940380](https://x.com/LangChain/status/2103152512693940380)
- GitHub highlighted parallel agent sessions in the Copilot app with separate Git worktrees and context, while Visual Studio Code shipped a release improving large session list management and enabling agent sessions in Dev Containers locally or remotely. [GitHub · 2104298872029741366](https://x.com/github/status/2104298872029741366) [Visual Studio Code · 2102835089914650832](https://x.com/code/status/2102835089914650832)

#### Worth trying

- Teams using Codex may want to keep an eye on OpenAI Developers' note that the Codex outage was resolved and the service is back up before relying on it for time-sensitive work. [OpenAI Developers · 2103650830604030228](https://x.com/OpenAIDevs/status/2103650830604030228)
- If agent sessions are getting long, try the VS Code release that makes large agent session lists faster to manage and supports running agent sessions in Dev Containers locally and on remote hosts. [Visual Studio Code · 2102835089914650832](https://x.com/code/status/2102835089914650832)
- For parallel coding work, try GitHub Copilot app sessions running in parallel with each session getting its own Git worktree and context for building, reviewing, and testing at the same time. [GitHub · 2104298872029741366](https://x.com/github/status/2104298872029741366)
- To debug data structures and algorithms, try the Debug Visualizer extension for VS Code that displays data changing as code runs, as illustrated with a linked list and QuickSort. [Visual Studio Code · 2102760396490719499](https://x.com/code/status/2102760396490719499)
